
# sage — screenshots for Discord verification

Public so the Discord review team can open the images linked in sage's
privileged intent application. Nothing here is part of sage itself.

sage is a statistics tracker for the Discord game **EPIC RPG**. It reads
EPIC RPG's own public messages and reports the numbers back to players who
have opted in with `sage start`.

- Privacy policy — https://gist.github.com/jbasalone/1dc0db3bf916b1edc08df62309357243
- Terms of service — https://gist.github.com/jbasalone/8749feca7f3eb206ff4f8717e3bff4a0
